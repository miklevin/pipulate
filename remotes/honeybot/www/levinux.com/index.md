## 1. Don't Know Where to Start?

What do you even call this desire? You see other people bending machines to their will starting with no more creativity than you have. They just seem to know stuff. Is it programming? Or just being technical?

- Why rely on others? You want this power for yourself!
- Maybe you think you're too old to learn new tricks—or too young to learn old tricks!
- Anything with a graphical user interface is generally tied to a particular hardware platform and a particular snapshot in time. All that knowledge becomes antiquated—all except the back-end.

## 2. The Short Stack: `LPvg` (Linux + Python + vim + git)

`LPvg` is the **least** software you could be using to do the most interesting things across the most fields, without needing to be a career programmer or risking obsolescence:

- **Linux (`*nix`)**: Runs everywhere from Raspberry Pis and old laptops to Macs, Windows WSL, and the cloud.
- **Python**: A language loved by beginners and pros alike—anything that can run Python can be a server.
- **vim**: A text editor you'll at first hate, then love for life.
- **git**: Lets you back up, move, and verify your code everywhere.

## 3. Under the Hood of Classic Levinux

Levinux is a tiny virtual server built on **QEMU** and **Tiny Core Linux** that runs on the desktop of Macs, Windows, and Linux PCs with a double-click:

- No installation or admin rights required.
- Driven by a plain-text `Recipe.sh` start script you can inspect and edit on the host.
- Download Classic Levinux: [https://github.com/miklevin/Levinux/archive/refs/heads/master.zip](https://github.com/miklevin/Levinux/archive/refs/heads/master.zip)
